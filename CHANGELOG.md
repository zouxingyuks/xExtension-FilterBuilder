# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-02-19

### Added

- FreshRSS extension scaffold (`metadata.json`, `extension.php`)
- Filter builder frontend (`static/filter-builder.js`)
  - Operator registry
  - Condition and group UI components
  - QueryBuilder (UI -> query string)
  - QueryParser (query string -> UI state)
  - Real-time preview and search actions
- Styling (`static/filter-builder.css`) with responsive and dark mode support
- i18n files (`i18n/en.php`, `i18n/zh-cn.php`)
- Node.js test scripts under `tests/`
- Open-source project files: `LICENSE`, `CONTRIBUTING.md`
